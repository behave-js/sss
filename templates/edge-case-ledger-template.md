# Edge Case Ledger

특정 경계·예외·실패·비전형 조건에서 발견한 사례를 누락 없이 추적하기 위한 색인이다. **모든 실패 경로나 Tension을 자동 등록하는 목록이 아니다.** 등록·추적의 기준은 [Edge Case 관리](../19-edge-case-management.md)를 따른다.

## 사례 목록

| EC ID | 제목·조건 | 관련 Scene/Beat/Closure | 근거 상태 | 처리 판단 | 검증 상태 | 추적 상태 | 상세 Record / 후속 작업 |
|---|---|---|---|---|---|---|---|
| | | | 관찰/추론/의도/미확인/충돌 | 미결정/반영/보류/범위 밖/수용/중복 | 미검증/진행/통과/실패/해당 없음 | 열림/종료/재개방 | |

## 누락 검사

- [ ] 개별 Record가 모두 Ledger에 등록되어 있고 중복 ID가 없다.
- [ ] Ledger의 정본·근거·검증·작업 링크가 유효하다.
- [ ] 처리 판단, 검증 상태, 추적 상태가 혼합되지 않았다.
- [ ] 종료한 사례에는 판단 이유, 근거 범위, 잔여, 재개방 조건이 있다.
- [ ] 사례에서 확정된 동작은 Scene·Beat·Prop·Edge·Closure의 정본에 환류됐다.
