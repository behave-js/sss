# Beat Catalog

Beat의 독립 상세 기록이 필요한 경우에 사용하는 프로젝트 색인이다. **Scene 문서가 Beat의 순서·배치를 설명하며**, 상세 Beat 기록은 `beats/<beat-id>.md`에 남긴다. 모든 Beat를 반드시 별도 파일로 만들 필요는 없다.

## 커버리지와 일관성 검사

- [ ] 독립 Beat 문서가 모두 이 Catalog와 소속 Scene에서 참조된다.
- [ ] 같은 Beat의 상세 변화가 Scene과 Record에 충돌하게 중복 정의되지 않는다.
- [ ] Beat ID가 안정적이며 트리거·상태 변화·근거가 추적된다.
- [ ] Edge Case와 비전형 분기가 필요한 경우 역링크로 연결된다.
