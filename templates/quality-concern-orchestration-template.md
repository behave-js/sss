# 품질 관심사 오케스트레이션(Quality Concern Orchestration)

이 템플릿은 품질 질문을 여러 위치(Position)·관념 스트림(Notion stream)·참조 렌즈(Reference Lens)·오케스트레이션 기능(Orchestration Function)에서 함께 판단할 때 사용하는 선택적 작업 뷰(Working View)다. 범용 온톨로지(ontology), 분야별 품질 체크리스트, 표준 적합성 평가표 또는 종합 점수표가 아니다.

관련 문서: [품질 관심사 프로필(Quality Concern Profile)](../14-quality-concern-profile.md), [오케스트레이션(Orchestration)](../12-orchestration.md), [관념(Notion)](../00-notion.md), [시맨틱 프로브(Semantic Probe)](../09-semantic-probes.md), [텐션 가이드북(Tension Guidebook)](../13-tension-guidebook.md).

## 식별과 범위(Scope)

- ID: `QCO-<scope>-###`
- 품질 질문·계기(Trigger):
- 대상 범위(Scope)와 판본:
- 포함한 맥락(Context)·실제 시나리오 자료(있는 경우):
- 제외한 범위:
- 현재 상태:

여기서 실제 시나리오 자료는 각본·사용 사례·운영 시나리오처럼 대상에 존재하는 자료를 뜻한다. Scenario-Semantic Synthesis(SSS)의 방법적 Scenario를 새 상위 객체로 기록하는 칸이 아니다.

## 분야 비종속 질문(Domain-uncommitted Question)과 품질 관심사(Quality Concern)

- 이름을 붙이기 전 감지·관찰:
- 대상·상황·영향:
- 분야 비종속 질문(Domain-uncommitted Question):
- 관심사군(Concern Family):
- 현재 채택한 구체 관심사(Concern)·작업 어휘(Working Vocabulary):
- 관련 주제(Subject) 후보:
- 아직 이름만으로 결정하지 않은 것:

## 참조 렌즈(Reference Lens)

| 분야·렌즈 | 가까운 정밀 용어 | 새로 드러낸 것 | 가리거나 약화한 것 | 비동일성 경계 | 현재 채택 여부·이유(Reason) |
|---|---|---|---|---|---|
| 소프트웨어 / 극작·서사 / 서비스 / 조직 / 기타 | | | | | |

분야 어휘를 제거하거나 흐릿하게 합치지 않는다. 어느 렌즈도 처음부터 대상의 범용 정의로 만들지 않는다.

- 비환원적 종합(Non-reductive Synthesis)을 위해 함께 남길 렌즈 차이·반례·미확인(Unknown):

## 위치(Position)와 관점(Perspective)

| 위치(Position)·이해관계 | 현재 맥락(Context) | 좋음·위험으로 보는 것 | 관념(Notion) 방향 후보 | 영향받는 액터(Actor)·씬(Scene)·완결(Closure) | 관찰하지 않은 범위 |
|---|---|---|---|---|---|
| | | | | | |

직책만으로 관념(Notion)의 이름을 정하거나 한 관점(Perspective)을 전체 참여자의 관점으로 일반화하지 않는다.

## 오케스트레이션 기능(Orchestration Function) and 배정(Assignment)

## 근거(Evidence)·프로브(Probe)·측정값(Measure)

| 관심사(Concern)·Scenario | 관찰(Observation) / 의도(Intent) / 추론(Inference) | 프로브(Probe) | 측정값(Measure) | 범위(Scope)·조건 | Blind spot | 해석 주체 |

## 트레이드오프(Trade-off)·충돌(Conflict)·텐션(Tension)

| 관계 | 트레이드오프(Trade-off) 후보 | 충돌(Conflict) | 감지된 텐션(Tension)과 관점 | 근거(Evidence) | 아직 모르는 것 |
|---|---|---|---|---|---|
| | | | | | |

트레이드오프(Trade-off) 후보 ≠ 텐션(Tension) ≠ 충돌(Conflict)

## 프로덕션(Production)과 EIFS — 사용할 때만

- 프로덕션 후보(Production Candidate):
- 품질 관심사(Quality Concern)가 설명하는 영향:
- E/I/F/S의 별도 이유(Reason)와 근거(Evidence):
- 개입 우선순위(Intervention Priority)와 탐색 우선순위(Exploration Priority):
- 관심사(Concern)에서 점수로 자동 변환하지 않았는가:

## 리플렉션(Reflection)

- 예상한 품질 의미:
- 실제로 실현·경험·운영된 의미:
- 채택한 분야 어휘가 잘 설명한 것과 놓친 것:
- 다른 참조 렌즈(Reference Lens)에서 새로 보인 것:
- 작업 어휘(Working Vocabulary)의 유지·수정·폐기 여부:
- 위치(Position)별 관념(Notion) 변화:
- 실제 트레이드오프(Trade-off)와 새 텐션(Tension):
- 측정값(Measure)이 보여주지 못한 결과:
- Matrix·권한(Authority)·인계(Handoff)의 실제 작동:
- 정본·저널(Journal)·새 프로덕션 후보(Production Candidate) 환류:

## 완결(Closure)

- 이번 판단에서 닫은 질문:
- 닫지 않은 질문:
- 남은 미확인(Unknown)·텐션(Tension)·영향:
- 다시 열 수 있는 맥락(Context)·근거(Evidence)·다른 렌즈·계기(Trigger):

이번 기록의 종료는 품질 관심사(Concern) 전체의 해결, 모든 위치(Position)의 합의 또는 관념(Notion)의 이름 고정을 뜻하지 않는다.
