# [텐션(Tension)의 임시 식별 이름]

**ID:** `TEN-<observer>-###`  
**상태:** 미해석/관찰 중/해석 후보 있음/평가됨/활용 결정/해소됨/잔류/보류  
**감지 형태:** 직접/관계적  
**작업 뷰(Working View):** Local/저널(Journal)/종결 상태(Closed)

> 제목은 감각을 찾기 위한 임시 이름이며 원인·성질·가치를 확정하지 않는다.

## 감지

- 감지자:
- 감지자의 위치(Position)·관점(Perspective)·경험:
- 대상:
- 감지 위치:
- 시점·대상 판본·상황:
- 가공하지 않은 감각의 표현:
- 다른 관점에서는 감지됐는가/감지되지 않았는가/관찰하지 않았는가:

## 궤적

| 시점/씬(Scene) | 강도 또는 상대 변화 | 증가·감소·축적·변형·해소·잔류 | 관찰 조건 |
|---|---|---|---|
| | | | |

강도는 선택 사항이며 해당 관찰자·맥락의 상대값이다. 객관적 품질 점수로 사용하지 않는다.

## 해석 후보 — 선택 사항

- 감각의 정체 후보:
- 원인 후보:
- 감지 위치와 다른 상류/하류 원인 가능성:
- 조사 범위와 반례:
- 아직 모르는 것:

## 평가 — 선택 사항

- 평가 관점과 목적:
- 도움이 될 가능성:
- 방해가 될 가능성:
- 중요도 판단과 근거:

텐션(Tension)의 존재와 강도만으로 중요도를 정하지 않는다.

## 활용 — 선택 사항

- 결정: 관찰/유지/강화/약화/이동/해소/보류/무조치
- 이유:
- 별도 Error/Warning/이슈(Issue)/완결(Closure)로 전환했는가:
- 결정 뒤의 텐션(Tension) 변화:

## 저널(Journal)·닫힘 — 장기 추적할 때만

- 저널(Journal) entry:
- 관련 constellation 후보:
- 종결 상태(Closed)로 이동했다면 종결 맥락(Closing Context)과 이유(Reason):
- 남은 감각·미확인(Unknown)·열린 완결(Closure):
- 재개방 신호(Reopen Signal):
- 재열림 이력:

종결 상태(Closed)는 텐션(Tension)의 완료나 영구 해소가 아니라 현재 적극 관찰에서 내려놓은 작업 뷰(Working View)다. 상세 역사는 저널(Journal)과 종결 상태(Closed) 문서에 연결하고 최초 감지 원문을 덮어쓰지 않는다.
