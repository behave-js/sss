# 텐션 종결 기록(Tension Closed)

이 문서는 현재 맥락(Context)과 근거(Evidence)에서는 적극적으로 추적하지 않기로 했지만 이력(History)과 재열림 가능성을 보존하는 작업 뷰(Working View)다. Archive, Completed List, 해결 실적표가 아니다.

관련 문서: [텐션 가이드북(Tension Guidebook)](../13-tension-guidebook.md), [텐션 저널(Tension Journal)](tension-journal-template.md), [텐션(Tension) 기록(record)](tension-record-template.md).

```text
종결 상태(Closed) ≠ Completed ≠ Resolved ≠ Deleted
```

## Reopen 이력

| 날짜·판본 | 텐션(Tension) | 새 맥락(Context)·근거(Evidence) | 이전 종결 이유(Closing Reason)의 당시 유효성 | 저널(Journal) 복귀 링크 |
|---|---|---|---|---|
| | | | | |

재열림은 이전 닫힘의 실패를 자동으로 뜻하지 않는다. 기존 종결 상태(Closed) 기록을 덮어쓰지 않고 새 이력으로 연결한다.

## 운영 원칙

- 종결 이유(Closing Reason)를 `해결됨` 한 단어로 축약하지 않는다.
- 잔여(Residual)와 재개방 신호(Reopen Signal)를 가능한 범위에서 남긴다.
- 오래됐다는 이유만으로 삭제하지 않는다.
- 종결 상태(Closed) 수를 진척률이나 성과로 사용하지 않는다.
- 새 맥락(Context)이 생기면 언제든 저널(Journal)로 되돌릴 수 있다.
