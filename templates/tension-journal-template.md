# 텐션 저널(Tension Journal)

이 문서는 여러 씬(Scene)·완결(Closure)·프로덕션(Production)·리플렉션(Reflection)·판본을 가로질러 적극적으로 관찰할 가치가 있는 텐션(Tension)의 궤적과 관계를 보존하는 작업 뷰(Working View)다. 이슈(Issue) backlog, 품질 점수, 정본이 아니다.

관련 문서: [텐션 가이드북(Tension Guidebook)](../13-tension-guidebook.md), [텐션(Tension) 코어(Core)](../01-tension.md), [텐션(Tension) ledger](tension-ledger-template.md), [텐션(Tension) 기록(record)](tension-record-template.md), [텐션 종결 기록(Tension Closed)](tension-closed-template.md).

## 운영 원칙

- 모든 텐션(Tension)을 저널(Journal)에 넣지 않는다.
- 순서와 빈도를 중요도나 품질로 읽지 않는다.
- 감지 원문을 후속 Interpretation으로 덮어쓰지 않는다.
- 감지 지점과 원인 후보를 분리한다.
- 저널(Journal) 자체를 의미 권위(semantic authority)로 만들지 않는다.
- 종결 상태(Closed) 이동 시 이력(History)을 삭제하지 않는다.
