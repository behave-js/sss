# 텐션(Tension) ledger

이 ledger는 이슈(Issue) backlog, 결함 목록, 품질 점수가 아니다. 특정 관점에서 감지됐지만 아직 원인·성질·가치가 확정되지 않은 감각을 잃지 않고 다시 찾기 위한 색인이다.

여러 구성·작업·판본을 가로질러 적극 관찰하는 기록(record)은 [텐션 저널(Tension Journal)](tension-journal-template.md)에 연결하고, 현재 적극 관찰에서 내려놓은 기록(record)은 [텐션 종결 기록(Tension Closed)](tension-closed-template.md)에 종결 이유(Closing Reason)·잔여(Residual)·재개방 신호(Reopen Signal)를 보존한다. Ledger의 상태와 저널(Journal)/종결 상태(Closed) 작업 뷰(Working View)는 중요도나 해결 여부를 뜻하지 않는다.

빈 ledger는 `텐션(Tension) 없음`을 뜻하지 않는다. 아직 관찰하지 않았거나 기록된 감지가 없을 수 있다.

## 운영 원칙

- 기록(record) 수를 목표나 품질 지표로 사용하지 않는다.
- 감지 원문을 후속 해석으로 덮어쓰지 않는다.
- 원인·평가·조치가 없어도 유효한 기록(record)으로 남긴다.
- 모든 기록(record)의 해석·해소를 완료 조건으로 삼지 않는다.
- 생산적 감각을 자동 제거하지 않고 미해석 상태를 자동 미화하지 않는다.
- 종결 상태(Closed)를 Completed·Resolved·Deleted로 읽지 않고 새 맥락(Context)에서 재열림을 허용한다.
