# 오케스트레이션(Orchestration) 레코드(Record)

이 문서는 여러 오케스트레이션 기능(Orchestration Function)·기능 배정(Function Assignment)·질문·작업 패킷(Work Packet)·인계(Handoff)·환류를 조율할 필요가 있을 때 사용하는 작업 뷰(Working View)다. 고정 워크플로(Workflow), 조직도, 승인 사슬 또는 작업량 관리표가 아니다.

관련 문서: [오케스트레이션(Orchestration)](../12-orchestration.md), [분석 절차](../05-analysis-workflow.md), [프로덕션(Production)](../10-production.md), [리플렉션(Reflection)](../11-reflection.md), [텐션 가이드북(Tension Guidebook)](../13-tension-guidebook.md), [품질 관심사 프로필(Quality Concern Profile)](../14-quality-concern-profile.md).

## 오케스트레이션 기능(Orchestration Function) and 배정(Assignment)

| 참여자 | 배정 기능(Assigned Function) | 책임(Responsibility) | May Decide / Change | Must Preserve | Return / Escalate |
|---|---|---|---|---|---|
| | 탐색(Exploration)/매핑(Mapping)/추적(Tracing)/종합(Synthesis)/설계(Design)/실현(Realization)/검증(Verification)/문서화(Documentation)/조율(Coordination) | | | | |

기능(Function)은 사람의 직책이나 세계 안의 액터(Actor) 역할(Role)이 아니다. 기능 배정(Function Assignment)은 현재 작업의 기능을 참여자에게 배정한 관계이며, 한 참여자에게 여러 기능(Function)을 배정할 수 있다.

종합 기능(Synthesis Function)은 현재 범위의 결과를 비교·연결하는 기능이며 Scenario-Semantic Synthesis(SSS) 전체 의미를 확정하는 권한이 아니다.

오케스트레이션(Orchestration) 종료는 대상 전체 분석 완료, 프로덕션(Production)·경험 완결(Closure) 종료, 텐션(Tension) 해소 또는 관념(Notion)의 이름 고정을 뜻하지 않는다.
